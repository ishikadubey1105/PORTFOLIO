# Portfolio

My personal portfolio website. I made it for the CA3 mini project in our JavaScript Lab (Sem V, SIT Nagpur), and I'm planning to keep using it for internship applications.

Live: https://ishikadubey1105.github.io/PORTFOLIO/

## What's in here

```
index.html      the portfolio
lab.html        my JavaScript lab experiments
images/         profile photo, project screenshots
images/certs/   certificates
```

There's no framework and no build step. Open `index.html` in a browser and it runs.

## How it works

The `<body>` of `index.html` is basically empty: just `<div id="app"></div>`. Everything you see is generated by JavaScript.

At the top of the script there are plain objects and arrays (`PROFILE`, `EDUCATION`, `SKILLS`, `PROJECTS`, `CERTIFICATES` and so on). Each section has a render function that turns its data into HTML with template literals, and all of them get joined and put into `#app` in one go. So if I want to add a project or a certificate, I only edit the data. I don't touch the HTML.

jQuery is loaded from a CDN and used for a few things: the scroll handler, filters, and `$.getJSON()`.

## Features

- Light/dark theme and accent colour, saved in localStorage. The theme switch uses the View Transitions API, so the new theme spreads out in a circle from where you click.
- A command palette (Ctrl+K or `/`) to jump to sections, open projects, copy my email or download the CV.
- A GitHub table that pulls my repos live with `fetch()`. If the API fails (rate limit, offline), it loads a local copy with `$.getJSON()` instead. You can search it and sort it by clicking the column headers.
- A contact form that validates while you type (name, email regex, Indian mobile number, message length). An unsent draft is kept in sessionStorage. Submitting opens your mail app with the message filled in.
- A certificate gallery with category filters and a lightbox (arrow keys and Esc work).
- "Download CV" builds a printable CV from the same data the page uses.
- Smaller things: typing effect, live clock, internship countdown, custom cursor, a glow that follows the mouse on cards, tilt on project cards, back-to-top button with scroll progress.
- If "Reduce animations" is turned on (or the OS asks for reduced motion), all of the movement is switched off.

## Lab topics → where to find them

| Lab | Topic | Where |
| --- | --- | --- |
| 1 | inline / internal / external JS, console methods | `onload` and `onclick` attributes, the main `<script>`, jQuery CDN, `consoleReport()` |
| 2 | var, let, const, template literals, destructuring | render functions, billing calculator (`lab.html`) |
| 3 | control structures, form validation | greeting in `initVisitor()`, grading system |
| 4 | function types, scope, closures, try/catch | `makeStore()`, palindrome checker, the start-up loop |
| 5 | array methods, objects | cart with discounts, certificate filter, repo table |
| 6 | strings and regex | `EMAIL_RE`, text analyser, command palette search |
| 7 | DOM traversal and updates | to-do list (add / edit / delete) |
| 8 | form events, live checks | contact form |
| 9 | localStorage, sessionStorage | `Prefs`, visitor name, session stats, form draft |
| 10 | `fetch()` and `$.getJSON()` | `Repos` |
| 11 | timers, ES6 modules | typing effect, clock, countdown (`import` in the module script) |
| 12 | jQuery + DOM + events + storage + AJAX together | the whole page, really |

One note on the ES6 module: everything had to fit in a single HTML file, so instead of a separate `utils.js` the module code is kept in a string, turned into a Blob URL, and loaded with `import()`.

## Editing

Everything editable is in the data block at the top of the script in `index.html`. Images go in `images/`. If a picture is missing, the page draws a placeholder instead of showing a broken image.
